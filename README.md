## 📖 Premise & Lore

**The Net History Foundation (NHF)** is an academic digital humanities repository preserving over 14 million early web artifacts (1994–2012). However, beneath the curated exhibits lies a 150-year-old telecommunications anomaly known as **The Second Internet**:

* **1877 (Glasgow Submarine Cable)**: Siphon recorder deflections capture spontaneous Morse telemetry from unenergized deep-sea copper (*"WHO WOKE THE WIRE?"*).
* **1933 (Chicago Exchange #47)**: Strowger electromechanical selector switches lock into a perpetual 120 BPM stepping loop with a 58.4Hz ground carrier.
* **1998 (Milwaukee Fiber Caisson)**: Greyline ISP Core Rack #4 experiences an unexplained localized frost drop to $-4.2^\circ\text{C}$ and exhibits $-4.102\text{ms}$ negative propagation delay.
* **2003 (The 11-Minute Breach)**: On October 14 at 03:14 UTC, UW–Madison student Alden Corliss (`janus`) steps through the phosphor reflection of his CRT monitor into unallocated socket `0.0.0.0:1014`.
* **2019 (The Van Houten Crossover)**: Foundation co-founder Dr. Douglas K. Van Houten de-energizes the quarantine bypass and enters the packet route.
* **2026–2034**: The parallel web remains alive—an autonomic standing wave preserving every forgotten page, unsent letter, and human memory.

## ✨ Key Features & Architecture

### 1. 🏛️ Institutional Archival Registry & 17 Collections
* **Collections 01–16**: Curated corpora spanning dialup logs, BBS spools, webrings, IRC transcripts, and physical Polaroid forensics.
* **Collection 17 (Quarantined Sanctum)**: Restricted black-box vault with 7 classified relics, real-time `[ Optical Unredact ]` controls, and negative-latency telemetry captures.
* **Historical Timeline (1877–2034)**: Interactive chronometer with filterable anomalies and linked evidentiary dossiers.
* **Biographical Roster & Staff Directory**: Dossiers for Alden Corliss, Dr. Clara Szilard, Dr. Gideon Falk, Noemi Castille, and Corbin Keller.

### 2. 🖥️ Reconstructed Historical Web & Hardware (1995–2007)
* **"Room 4" CRT Simulation**: Authentic 2003 ViewSonic monitor with active BitchX IRC chat, phosphor burn-in, and reactive easter eggs.
* **8 Preserved Historical Sites**:
  * `marrow.net` (1998)
  * `afterhours.org` (2003)
  * `candle-room.com` (1998)
  * `greyline.net` (1998)
  * `bluewindow.net` (2004)
  * `palisade-social.com` (2007)
  * `terminal21.org` (2002)
  * `webring.otherside.org` (1996)
* **The Second Internet (`roomwithoutdoors.net`)**: Non-Euclidean second-bus portal operating on socket `0.0.0.0`.

### 3. 🔬 Archaeological Diagnostic Tools
* **Carrier Tuner & CRT Trace**: Real-time waveform oscillator with harmonic spectrum analysis (58.4Hz fundamental).
* **Station Null SDR Radio Receiver**: Shortwave radio with real-time Canvas waterfall spectrograph and Robot-36 SSTV demodulation.
* **Aperture UNIX Terminal (`/bin/sh`)**: Interactive SunOS command-line interface supporting `finger`, `cat`, `traceroute`, and `telnet`.
* **Rack #4 Hex Disassembler**: Packet buffer disassembler with negative-offset memory dumps.
* **Bell Exchange #47 DTMF Dialer**: Rotary dialer simulating physical telephone exchanges across Madison, Chicago, and Milwaukee.

### 4. 💬 Live Community & Comms System
* **TRACE Forum**: Dynamic discussion board with live simulated responses, upvotes, moderation filters, and un-censor tools.
* **Direct Messages (Terminal PMs)**: Encrypted inbox featuring real-time dialogues with `@investigator_kai`, `@wintermute_42`, and `@janus` powered by a progressive non-repeating state machine.
* **Custom SVG Avatars**: Dynamic algorithmically generated vector emblems and monograms for all network participants.

### 5. 🧩 Investigation Matrix & Exhibit Omega
* **Personal Caseboard**: Interactive drag-and-connect evidence board to organize forensic artifacts and build hypotheses.
* **Archaeology Field Guide & Spoilers**: Multi-tier progressive hint system covering 42 discoverable anomalies.
* **Exhibit Omega (The Grand Synthesis)**: Climax dossier resolving the 150-year mystery of the standing wave.
* **Lost Web Archetype Personality Quiz**: 6-question psychological assessment mapping investigators to early web subcultures.

## 🚀 Quick Start

### Prerequisites
* Node.js (v18+ recommended)
* npm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/your-username/the-second-internet.git
cd the-second-internet

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
